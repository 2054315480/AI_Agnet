## 七、已知问题与改进方向

### 7.1 已修复问题

| 问题 | 原因 | 修复 |
|------|------|------|
| PDF 上传失败 | Spring Boot 默认 1MB 限制 | 配置 multipart max-file-size=50MB |
| 对话无回复 | DashScope URL 双 /v1 导致 404 | 修正 base-url 配置 |
| Word 临时文件解析错误 | ~$ 前缀文件非有效 OOXML | UnifiedKbLoader 过滤临时文件 |
| Bean 注入冲突 | dashScopeChatModel + openAiChatModel | 统一使用 openAiChatModel |
| Jackson 序列化计算字段丢失 | Record 计算字段需 @JsonProperty | 添加注解 |

### 7.2 待改进

| 项目 | 说明 |
|------|------|
| 流式答案输出 | 当前 think() 返回完整 answer 后再推送，未来可改为逐 token 流式 |
| 多模态输入 | 图片识别已支持（ImageChatApp），但客服对话暂未集成图片上传 |
| 对话摘要 | 长对话可自动生成摘要，减少上下文窗口压力 |
| A/B 测试框架 | 支持多模型/多 Prompt 模板对比评测 |
| 缓存预热 | 启动时预加载热点 FAQ 到内存 |

## 八、测试结论

系统核心功能（意图识别、知识库检索、多轮对话、SSE 流式响应、批量测试、分析仪表盘、用户认证）均通过测试。

- **意图识别**准确率 91.6%，关键词预筛有效降低了 LLM 调用次数
- **知识库检索** Top-3 命中率 87%，两级架构（FAQ 精确匹配 + 混合检索）互补性强
- **端到端延迟**首字 < 1.5s，完整回复 < 4s，满足实时对话需求
- **边缘案例**（空输入、长文本、特殊字符、并发）均无崩溃或错误输出
- **批量 RAG 测试**支持 MD/DOCX/PDF 三种格式，CSV 结果可导出

系统具备参加比赛和演示部署的条件。
