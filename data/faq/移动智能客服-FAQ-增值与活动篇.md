## 一、增值业务类（SP/CP）

### Q1：我的账单里每个月多扣10块钱，查下来是“和教育”，这是什么？怎么退？
**A**：
- **和教育**：家校互动业务，由学校老师邀请开通，家长可接收通知、作业、考勤
- 退订方式：
  1. 发送 `0000` 至 `10086`，回复“和教育”对应序号
  2. 发送 `TDJYJY` 至 `10086`
  3. 联系孩子班主任告知不再使用，老师后台删除号码
- 退费：若未经您同意代开（老师未告知），可申请退近3个月费用

### Q2：移动云盘（原和彩云）免费空间多大？怎么取消自动备份？
**A**：
- 普通用户：20GB，PLUS会员：1TB
- 取消自动备份：打开“中国移动云盘”APP → 设置 → 相册自动备份 → 关闭
- 注销云盘：APP内“账户与安全”→ 注销云盘（不影响移动号码使用）
- 注意：关闭自动备份后，已上传的文件仍会占用空间

### Q3：咪咕视频会员能几个人同时用？
**A**：
- 咪咕视频普通会员：**最多3台设备登录**，但**同时仅1台**观看
- 咪咕视频钻石会员：**同时2台**观看
- 家庭共享：不提供类似腾讯视频的家庭共享功能

### Q4：不小心点了某个链接，被扣了20块，能申诉吗？
**A**：可能为**CP代收费**（如某个小说/游戏阅读扣费）。处理方法：
1. 立即发送 `0000` 至10086，退订该业务
2. 申诉：拨打10086转人工 → 要求“不知情扣费申诉”
3. 移动会调取订购记录：若为**免密支付**（未输入验证码/短信确认）→ 可全额退费
4. 若曾主动点击“确认订阅” → 移动不退款，但可协助联系CP协商

### Q5：怎么彻底关闭移动所有的增值业务代收费功能？
**A**：发送 `GBDXSJ` 至 `10086`，可关闭“第三方代收费”权限。  
关闭后，所有游戏、阅读、视频等SP业务将无法扣费，但也会影响正常使用（如您主动买咪咕会员也会失败）。  
恢复方法：发送 `KTDXSJ` 至10086。

## 二、会员与权益类

### Q6：移动PLUS会员到底划不划算？主要有什么权益？
**A**：月费19.9元（首月9.9元），主要权益：
| 权益 | 价值参考 |
|------|----------|
| 任选1款视频会员（爱奇艺/腾讯/B站/优酷/芒果） | 市场价25元 |
| 话费充值9.8折（每月上限省20元） | 最高20元 |
| 线下商户券（星巴克满30减5，KFC套餐减8） | 券包约20元 |
| 1TB移动云盘空间 | 原价10元/月 |

**结论**：如果你每月必用视频会员，且话费超过100元，PLUS会员比较划算。

### Q7：我买了PLUS会员，选的视频会员怎么领？
**A**：
- 路径1：中国移动APP → PLUS专区 → 权益领取 → 每月1日0点开放领取
- 路径2：发送 `PLUS` 至10086，获取领链接
- 注意：**每月只能选1款**，选定后当月不可更改，次月可重选

### Q8：全球通用户有哪些专属权益？
**A**：全球通（银卡/金卡/白金卡/钻石卡）权益：
| 等级 | 权益 |
|------|------|
| 银卡（年消费≥3000元） | 机场/高铁贵宾厅每年4次 |
| 金卡（≥6000元） | 贵宾厅8次 + 免费换手机电池1次 |
| 白金卡（≥12000元） | 贵宾厅12次 + 免费国内酒店住宿1晚 |
| 钻石卡（≥24000元） | 全部权益 + 专属客户经理 |

**开通方式**：消费达标自动升级，无需申请。

## 三、宽带与电视类

### Q9：宽带网速慢，怎么自查？
**A**：请按顺序排查：
1. **测速**：使用“中国移动测速”APP或Speedtest，对比套餐速率（100M/200M/500M/1000M）
2. **重启设备**：光猫+路由器断电5分钟
3. **有线直连**：电脑网线连接光猫LAN口拨号测试，若速度正常→路由器问题，否则→移动线路问题
4. **Wi-Fi干扰**：用手机APP“Wi-Fi分析仪”看信道拥挤，手动路由器后台改信道

若以上无效，请发送 `GZ` 至10086报修。

### Q10：搬家了，宽带能迁移吗？
**A**：可以，为您提供“移机”服务：
- 费用：**100元/次**（部分融合套餐首年免费移机1次）
- 流程：拨打10086 → 宽带移机 → 预约新地址上门时间
- 条件：新地址必须有移动光纤覆盖，且原地址宽带未欠费

### Q11：移动IPTV的频道列表在哪里看？
**A**：
- 机顶盒：按遥控器“菜单” → 频道列表
- 在线查看：中国移动APP → 宽带电视 → 频道预告
- 客服辅助：发送 `IPTVPD` 至10086，获取本省频道表链接

### Q12：我可以自己买路由器替换移动送的吗？
**A**：可以。但注意：
- 移动配的光猫**不能替换**（需注册LOID认证）
- 您可在光猫LAN口后，自行接任何品牌路由器（推荐TP-Link/小米/华为）
- 要求千兆口：若您套餐≥300M，请确保路由器WAN口支持千兆，否则网速受限

## 四、国际及港澳台漫游类

### Q13：我要去美国10天，买哪种漫游包最便宜？
**A**：推荐“30元/天畅享包”（每天不限量，达2GB后限速256kbps）。  
10天总价300元。若需求仅是微信、导航，可选“一带一路多国包”：19.9元/天（总量1GB高速后限速）。

### Q14：漫游时怎么打电话最便宜？
**A**：
- **打回中国大陆**：直接用手机拨打（按漫游资费，如美国0.99元/分钟）
- **打漫游地当地**：也用手机拨（美国0.99元/分钟）
- **免费渠道**：通过Wi-Fi使用微信语音/WhatsApp
- **注意**：关闭“数据漫游”时也能接打电话，不会产生天价流量费

### Q15：我忘了开通漫游，人已在国外，能补开吗？
**A**：可以。
- 通过中国移动APP（需有网络，可使用国外Wi-Fi）→ 国际漫游 → 立即开通
- 发送 `GMKT` 至 `+8613800100186`（国际短信费用约0.5元/条）
- 开通后30分钟内生效

### Q16：漫游时手机无法上网，但能打电话？
**A**：1. 设置→蜂窝网络→开启“数据漫游”；2. 手动选网（关闭自动，选择当地信号强的运营商）；3. APN设置：新建APN，名称和接入点均填写 `cmnet`。

## 五、营销活动类

### Q17：收到短信说“充50送50”，真的假的？
**A**：部分真实。判断方法：
- 确认发送号码是否为 `10086`（伪造号码可能仅为“10086”或“10658139”开头）
- 不要点击短信里的短链接（如t.cn/xxx），应登录APP首页查看活动专区
- 典型套路：送的是“优惠券”（分10个月给，每月5元），非直接送话费

### Q18：老用户可以参加“新用户特惠”活动吗？
**A**：通常**不能**。活动页面会注明“限新入网用户”（入网≤7天）。但部分活动有“老用户回馈专区”，可发送 `LHYH` 至10086查询您专属的活动。

### Q19：怎么查我名下有没有合约还没到期？
**A**：
- 短信：发送 `CXHY` 至 `10086`（查询合约）
- APP：我的 → 我的合约 → 展示所有进行中合约及到期日
- 若有购机合约，提前解约需支付手机剩余价款

### Q20：移动经常打电话推销套餐升级，能屏蔽吗？
**A**：
- 屏蔽营销电话：发送 `JX` 至 `10086`（加入“免营销名单”），15天后生效
- 屏蔽效果：不再接听10086外呼推销，但短信活动通知仍会收到
- 取消屏蔽：发送 `QXJX` 至10086

## 六、投诉与处理流程

### Q21：投诉网络差，等了15天还没解决，怎么升级？
**A**：
1. 再次拨打10086 → 要求“升级投诉”
2. 投诉编码请记下（如 WX20260427-001）
3. 若仍不满意，向**通信管理局**申诉：
   - 电话：12300
   - 网站：https://yhssglxt.miit.gov.cn
4. 通管局受理后，移动须在5个工作日内出具正式答复

### Q22：客服态度差，怎么投诉那个客服本人？
**A**：
- 记住客服工号（通话结束后系统会语音播报，或短信发送）
- 再次拨打10086 → 转人工 → 要求“投诉上一个客服”
- 或登录中国移动APP → 我的 → 意见反馈 → 填写工号和事发时间
- 移动会调取录音，核实后会对客服进行绩效考核扣减

## 七、政企产品类

### Q23：我开了个小公司，只有3个人，能办移动商务宽带吗？
**A**：可以。推荐“政企通”套餐：
- 月费199元：含 1000M宽带 + 3张手机卡（共享100GB流量+2000分钟）
- 附加功能：免费固定IP（需备案）
- 办理：拨打 `10086-8` 进入政企专席，或联系当地移动客户经理

### Q24：集团的视频会议系统怎么收费？
**A**：移动云视讯：
- 免费版：30方 × 45分钟/场
- 企业版：980元/年，支持100方 + 不限时长 + 录制回放
- 硬件终端：购买Polycom或华为终端，移动可协助配置（费用约8000元/套）

## 八、其他特殊场景

### Q25：手机卡坏了（物理损坏），但人在国外，怎么补？
**A**：
1. 可联系家人代办？**不可以**，补卡必须本人携带身份证。
2. 可通过中国移动APP申请“远程补卡”（仅限部分省份试点），需人脸识别+快递到国外地址（邮费较贵）
3. 若无解，回国后补卡。

### Q26：我母亲去世了，她的移动号码我想保留，怎么过户？
**A**：属于“继承过户”，需要：
- 死亡证明
- 继承人身份证
- 户口本（证明亲属关系）
- 到归属地营业厅办理，免过户费
- 号码原合约继续执行，不可解约

### Q27：怎么设置防骚扰（拦截诈骗电话）？
**A**：推荐使用“中国移动高频骚扰电话防护”：
- 开通：发送 `KTFSR` 至 `10086`
- 功能：系统拦截诈骗/骚扰/推销号码，会短信通知被拦截记录
- 管理：关注微信公众号“中国移动高频骚扰电话防护” → 设置黑白名单

### Q28：移动有没有不限量套餐？
**A**：目前中国移动**已停售**真正的不限量（达量不限速）套餐。现所有套餐均设有流量上限（40GB-200GB），超出后降速至1Mbps或3Mbps，称为“达量限速”，不限量但体验差。

### Q29：eSIM一号双终端怎么开通？
**A**：
- 支持设备：Apple Watch蜂窝版、部分安卓手表（华为Watch 4/小米Watch 2 Pro等）
- 开通：中国移动APP → eSIM专区 → 一号双终端 → 手表端扫码
- 月费：10元/月（前6个月免费）
- 功能：手表可独立通话上网，共享手机号码和套餐

### Q30：我在移动买了手机，7天无理由退换吗？
**A**：移动营业厅和线上商城支持**7天无理由退货**（需手机未激活、无人为损坏、包装完整）。  
但**合约购机**（0元购机那种）不支持无理由退货，仅支持质量问题换货。
