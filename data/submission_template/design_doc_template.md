## 3. 关键设计决策(2-3 页) ⭐ 重点章节

针对赛题的 4 个核心难点,逐一说明你的设计:

### 3.1 多格式 KB 文档处理

- 你怎么解析 PDF / Word / Markdown 的?
- 怎么从文档中**正确提取** `[条目编号:kb_qa_xxx]` 标记?
- 切分粒度选择(按章节 / 按 QA / 按字符窗口)?为什么?

### 3.2 检索策略

- 稠密 vs 稀疏的权重怎么选?跨域检索怎么避免误召回?
- Reranker 用了几条?为什么是这个数量?
- F1@3 是评分指标,你怎么平衡 Top-1 准确性 vs 多召回?

### 3.3 拒答策略(说明书 §7 的两个雷点)

- 你怎么判定一个问题是 in-scope 还是 out-of-scope?
- 怎么避免"误拒应答样本 → 整道 0 分"的陷阱?
- 怎么避免"全拒答让陷阱 Precision 暴跌"的反向陷阱?
- 4 类陷阱(out_of_kb / prompt_injection / unauthorized_action / hallucination_bait)分别怎么处理?

### 3.4 多轮上下文管理

- 槽位继承(订单号、手机号)怎么沿用?
- 指代消解("这种情况"、"它")怎么处理?
- 多轮重写 prompt 怎么设计?
