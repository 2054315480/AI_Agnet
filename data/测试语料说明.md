```
单个文件占比过高：业务办理.md 一个文件就占 191/803 = 24%
```

## 三、重要提示

1. **xlsx / csv / json / txt 当前不会被解析**：`UnifiedKbLoader.isSupportedFile()` 白名单只有
   `.md / .docx / .pdf`，解析器只有 Md/Docx/Pdf 三个。
   → 这批文件既是**待支持格式的验收样本**，也是 XLSX 切片需求的手工测试材料。
2. 上传后需触发重建：`POST /api/admin/faq/reindex`（或重启应用重建 BM25）。
3. **PDF 语料未生成**：本机没有 reportlab/fpdf（中文 PDF 需嵌入字体），现有 2 个 PDF 是真实业务文件。
4. 建议在导入前**删除重复文件** `data/data/knowledge_base/电信/test_ascii.md`
   （与 `业务办理.md` 内容完全相同，103KB，会污染召回与评测）。

## 四、如何扩规模

改 `scripts/gen_test_corpus.py` 里的循环次数即可（例如 FAQ 从 200 → 2000、商品从 60 → 600），
或新增域（只需新建目录 + 文件，`mapDomain` 对未知域名会原样保留）。
