# 支付相关常见问题

## 支付方式有哪些？
我们支持以下支付方式：

1. **支付宝**（推荐）— 即时到账
2. **微信支付** — 即时到账
3. **银行卡支付** — 支持主流银行借记卡/信用卡
4. **花呗分期** — 3/6/12期免息（订单满500元）
5. **Apple Pay** — iOS 用户推荐

所有支付方式均享受同等售后保障。下单后请在30分钟内完成支付，超时订单将自动取消。

## 如何申请退款？
申请退款的步骤：
1. 进入「我的订单」页面
2. 找到需要退款的订单
3. 点击「申请退款」按钮
4. 选择退款原因（质量问题/不想要了/发错货/描述不符/其他）
5. 上传相关凭证照片（如有）
6. 提交申请

退款审核时间为1-2个工作日。审核通过后：
- 支付宝/微信支付：即时到账
- 银行卡：3-5个工作日
- 花呗/信用卡：次月账单抵扣

## 支付失败怎么办？
支付失败的常见原因和解决方法：

| 原因 | 解决方法 |
|------|----------|
| 余额不足 | 更换支付方式或充值后重试 |
| 银行卡限额 | 联系发卡行提高单笔限额 |
| 网络超时 | 切换网络后重新支付 |
| 订单已过期 | 重新下单（订单保留30分钟） |
| 系统维护 | 稍后再试或更换支付方式 |

如果多次支付失败，建议：
1. 检查银行卡是否开通了在线支付功能
2. 确认支付密码输入正确
3. 联系银行客服确认是否有限制

## 可以开发票吗？
可以。下单时在结算页面勾选「需要发票」：
- **电子发票**：下单后24小时内发送至邮箱（推荐）
- **纸质发票**：随包裹一起寄出

发票类型：
- 个人：提供收件人姓名即可
- 企业：需提供公司名称和税号

如需补开发票，请在收货后30天内联系客服。

## 分期付款怎么计算？
花呗分期费率（订单满500元可分期）：

| 期数 | 手续费率 | 每期手续费示例（以¥799为例） |
|------|----------|------------------------------|
| 3期 | 0% | ¥0（免息） |
| 6期 | 0% | ¥0（免息） |
| 12期 | 0% | ¥0（免息） |

当前所有分期均免手续费，活动截止日期以页面提示为准。
