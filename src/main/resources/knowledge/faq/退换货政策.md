# 退换货政策常见问题

## 退换货政策是什么？
我们的退换货政策如下：

**退货政策：**
- 自签收之日起7天内可无理由退货
- 商品需保持原包装、配件齐全、未使用
- 定制商品、内衣等特殊商品不支持无理由退货

**换货政策：**
- 自签收之日起15天内可申请换货
- 仅支持同款商品不同规格的换货

**退款时效：**
- 审核通过后3-5个工作日内退款
- 退款将原路返回至您的支付账户

## 收到商品有质量问题怎么办？
如果收到的商品存在质量问题：
1. 请在签收后7天内拍照留证
2. 进入「我的订单」→ 选择对应订单 → 点击「申请售后」
3. 选择「质量问题」，上传照片凭证
4. 描述具体问题，提交申请

处理流程：
- 客服将在24小时内审核
- 审核通过后免费上门取件
- 确认收到退货后立即安排换货或退款

质量问题的退换货运费由我们承担。

## 退货运费谁承担？
- **无理由退货**：运费由买家承担（约8-12元）
- **质量问题退货**：运费由我们承担，免费上门取件
- **发错货/漏发**：运费由我们承担
- **七天无理由退货且购买了运费险**：运费由保险公司赔付

建议：购买商品时可以选择运费险（0.5元），退货时可抵扣运费。

## 退款多久能到账？
退款到账时间取决于支付方式和银行处理速度：

| 支付方式 | 到账时间 |
|----------|----------|
| 支付宝 | 1-2个工作日 |
| 微信支付 | 1-2个工作日 |
| 银行卡 | 3-5个工作日 |
| 花呗 | 次月账单抵扣 |
| 信用卡 | 次月账单抵扣 |

退款进度可以在「我的订单」→「退款详情」中实时查看。

## 换货可以换其他商品吗？
换货仅支持同一商品的不同规格（如颜色、尺寸），不支持更换为其他商品。

如果想要其他商品，建议：
1. 申请退货退款
2. 重新下单购买新商品
这样可以更快拿到想要的商品，避免等待换货库存。
